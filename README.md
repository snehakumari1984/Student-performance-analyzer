# 📊 Student Performance Analyzer

A Python-based web application built with Streamlit to analyze student academic performance using marks and attendance data.

## 🚀 Live Demo

[Click here to use the application] (https://student-performance-analyzer-ujkxfwcjfn6drwunwbjvq7.streamlit.app/)

## 📌 About the Project

The Student Performance Analyzer helps users understand student performance through data analysis and interactive visualizations. It calculates average marks, analyzes attendance, and categorizes students based on their average scores.

## ✨ Features

- Upload student data using a CSV file
- Calculate average marks across subjects
- Analyze student attendance
- Categorize performance as Excellent, Good, Needs Improvement, or At Risk
- Filter records by student name
- Visualize subject averages and student performance using interactive charts
- Identify subjects where students may need improvement
- Download analyzed results as a CSV file

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- CSV

## ⚙️ Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/snehakumari1984/student-performance-analyzer.git
   ```

2. Open the project folder:

   ```bash
   cd student-performance-analyzer
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```

## 📈 How It Works

1. Load the sample student dataset or upload a CSV file.
2. View calculated averages and attendance statistics.
3. Explore performance categories and interactive charts.
4. Identify subjects that may need improvement.
5. Download the analyzed data for further use.

## ⚠️ Disclaimer

Performance categories are based on predefined score thresholds for educational demonstration. They are not an official academic grading or assessment system.
